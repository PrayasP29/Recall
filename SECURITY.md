# Security policy

## Reporting a vulnerability

Please do not report exploitable vulnerabilities in a public issue, pull request, or discussion.

When GitHub private vulnerability reporting is enabled for this repository:

1. Open the repository's **Security** tab.
2. Select **Advisories**.
3. Choose **Report a vulnerability** and provide the affected file or feature, reproduction steps, impact, and any suggested mitigation.

This creates a private report visible to the repository maintainers. If the reporting option is not shown, GitHub private vulnerability reporting is not currently enabled; do not publish exploit details. Contact the maintainers through a private GitHub channel and ask for a secure reporting route.

## What to include

- A concise description of the vulnerability and its impact.
- Reproduction steps or a proof of concept that does not expose real credentials or personal data.
- Affected versions, commits, or browser environments.
- Any mitigation or remediation ideas.

Please allow maintainers reasonable time to investigate and coordinate a fix before public disclosure. Do not include passwords, session cookies, CSRF tokens, or other secrets in a report.
